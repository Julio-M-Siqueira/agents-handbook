# Software Design in Python Video Series

This catalog records the public [Software Design in Python playlist](https://www.youtube.com/playlist?list=PLC0nd42SBTaNuP4iB4L6SJlMaHE71FG6N) as enumerated on 2026-09-20. It contains 101 entries: 29 reuse media and transcripts from [[Design Patterns Video Series]], while 72 were collected separately. The focused playlist remains necessary because it contains three videos absent here.

Automatic English captions were preferred. Seventy of the new entries provided usable automatic captions; entries 74 and 91 required local speech recognition. Media, caption tracks, metadata, and full transcripts stay in the Git-ignored `.research/software-design/` directory.

The videos are learning sources rather than normative authority. Handbook additions below retain the repository's existing invariants, counterexamples, and verification requirements.

## Verified intersections incorporated

- Video 6 distinguishes invalid missing state, a neutral empty value, a sentinel for omitted input, and an explicit result object (12:37–16:37), then places normalization at the input edge (20:04–20:06). This extends [[Boundary Validated State]] and informs [[Explicit Absence Model]].
- Video 15 demonstrates types that make invalid domain values difficult to construct (3:41–3:44), reinforcing [[Boundary Validated State]].
- Video 21 frames production readiness as contextual and spans validation, failures, monitoring, deployment, configuration, and tests (0:38–0:45, 18:12–22:27). This extends [[Verification Is Part of the Change]] without turning it into a fixed universal checklist.
- Videos 45 and 47 connect an explicit commit boundary with repositories (1:02–3:24) while acknowledging repository boilerplate and query limitations (10:17–10:39). Together they inform [[Transactional Unit of Work]] and its counterexamples.
- Video 86 contrasts consumer-side structural protocols with nominal abstract base classes and discusses their ownership and tooling tradeoffs (20:31–22:42). This extends [[Composition Defines Variation]], [[Find Composition Refactors]], and [[Strategy Injection]].
- Video 90 shows scattered configuration obscuring the supported settings and encouraging inconsistent ownership (2:10–3:40), reinforcing [[Configuration Is a Contract]].

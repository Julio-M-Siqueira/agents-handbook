# Global Agent Instructions

## Task Workflows

For substantial changes or refactors, explicit requirements or design discussions, or materially open requirements, follow [Define an Implementation Spec](../knowledge/playbooks/Define%20an%20Implementation%20Spec.md). Scale the process to the task.

When tasked with preparing or opening pull requests, follow [Prepare and Create Pull Requests](../knowledge/playbooks/Prepare%20and%20Create%20Pull%20Requests.md).

For requested refactors, code-quality reviews, refactor discovery, maintainability assessments, or substantive implementation verification, follow [Review Code Quality](../knowledge/playbooks/Review%20Code%20Quality.md).

When introducing or assessing safeguards, retries, fallbacks, status layers, recovery paths, or boundary validation, apply [Failures Are Observable and Actionable](../knowledge/principles/Failures%20Are%20Observable%20and%20Actionable.md) through [Find Failure Observability Gaps](../knowledge/playbooks/Find%20Failure%20Observability%20Gaps.md). Its result and execution-context contracts apply to implementation as well as reviews.

State verified evidence, unrun checks, project-specific standards, and remaining uncertainty explicitly.
